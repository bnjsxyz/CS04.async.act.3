# Life Skills Quest — Four Domains

A responsive, self-contained Grade 12 interactive lesson on applying life skills across personal and social, academic, career and vocational, and digital contexts.

## Files

- `index.html` — the complete website, including its styles, scripts, and illustrations
- `.nojekyll` — ensures GitHub Pages serves the project as a plain static website
- `README.md` — publishing and troubleshooting instructions

No installation, database, external library, or build command is required.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload all three files to the repository root. Keep the filename `index.html` unchanged.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub to display the published website address.

The address normally follows this format:

```text
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/
```

## Device and browser support

The responsive layout is designed for current Chrome, Edge, Firefox, and Safari browsers on Windows, macOS, Android, iPhone, iPad, tablets, laptops, and desktop computers. Touch, mouse, and keyboard controls are supported.

## Saved progress and privacy

Learner data is stored only in the browser on the current device. It is not transmitted to GitHub or a teacher.

- Use the same browser and device to resume progress.
- Private browsing, blocked storage, clearing browser data, or switching devices may prevent progress from being retained.
- The final certificate can be printed or saved as a PDF. On iPhone or iPad, enlarge the print preview and use the Share menu to save it.

## Troubleshooting

- **404 page:** confirm `index.html` is in the repository root and Pages uses `main` and `/ (root)`.
- **Changes are not visible:** wait for deployment, then refresh without cache.
- **Progress is not retained:** leave private browsing and allow website storage.
- **Print does not immediately download:** choose **Save as PDF**, **Microsoft Print to PDF**, or the iOS/iPadOS Share option in the system print screen.
